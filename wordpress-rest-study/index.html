Runtime and mechanism

WordPress 7.1.3 · PHP 8.3.33 · WP_REST_Server · WP_SQLite_DB.

  • The permission callback checks the edit_posts capability separately from nonce validity.
  • Title and email validation happen before updating the submission option.
  • The valid request returned 201 and saved Synthetic form entry with sample@example.test.

The fixture calls rest_do_request() and sets synthetic users in-process. The source and unchanged raw report are available for inspection.

Limits of the evidence

These checks do not cover HTTP, browser cookies, login sessions, network CSRF behavior, persistence after process exit, production MySQL, third-party form plugins or payment integrations. Unchanged state refers only to the named submission option, not every database table or cache.

The fixed synthetic fixture is for an isolated Playground environment. It is not a production plugin or an assessment of a customer site. No customer files, real account credentials or WordPress runtime bundle are included.

Method: AI-assisted code authoring, with execution evidence produced by WordPress. The existing test was not rerun to prepare this page.
