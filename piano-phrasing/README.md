# Evening Margin — piano phrasing study

An eight-bar, self-initiated study by **Hx Works**. This is original code-authored, AI-assisted composition and MIDI programming, not a recording of a pianist or a client project. No client audio, MIDI or existing song was used as an input.

[Listen to the comparison](comparison.mp3) · [Straight MIDI](straight.mid) · [Phrased MIDI](phrased.mid)

The same 28 melody pitches occur in the same order in both versions. The first uses fixed tempo and dynamics with block chords. The second uses a bass-and-chord accompaniment, a deliberate dynamic arc, note-length changes, pedal releases, phrase breaths and cadential slowing. The score is eight bars of 3/4 in C major. MIDI files use format 1, three tracks, 480 PPQ and GM Acoustic Grand Piano.

The combined preview lasts approximately **39.29 seconds**, including rendered decay and a one-second separator. The phrased version starts at **19.34 seconds**. A common gain was applied to the combined recording, preserving relative dynamics between the two versions.

## Render and checks

- MIDI binary readback, melody preservation, final note/pedal release, duration and PCM clipping checks. The combined PCM peak is approximately -2 dBFS, with zero clipped samples.
