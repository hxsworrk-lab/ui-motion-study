# After Hours — two Hx Works motion studies

Original, self-initiated six-second vertical typography loops for a minimalist corporate/life direction. Not customer work, travel footage, a commissioned trial or proof of After Effects/Premiere proficiency. No audience/retention/client result is claimed.

- `hx-tabs-loop.mp4`: fictional tab clutter resolves into a single focus.
- `hx-call-loop.mp4`: a fictional quick call stretches into a longer interruption.
- Each is 1080 × 1920, 30 fps, H.264/yuv420p with original synthesized stereo audio. Actual decode and waveform details are in `render-receipt.json`.
- All graphics, wording and motion are code-authored. No third-party pictures, recordings, customer assets, logos or private data are used. Hx Works is plain text, preserving the existing brand rather than inventing a replacement mark.
- Existing Windows Segoe UI fonts are rendered into pixels only; font files and FFmpeg executables are not distributed. The previously checked Microsoft Font FAQ permits rendered graphics/video, not font redistribution: https://learn.microsoft.com/en-us/typography/fonts/font-faq
- Render with the existing Python/Pillow and FFmpeg installations: `python minimal-loops-20261017/render_minimal_loops_20261017.py` from the income workspace root. The source does not install dependencies, fetch files or contact a network. It overwrites only its named outputs inside this study folder.

Browser playback, visual observations, exact hashes, audio and loop limitations are recorded separately after checking the actual MP4s. Mathematical source endpoint equality is not a blanket perceptual-seamlessness guarantee. Direct new purchases are zero; model/tool/hosting monetary costs remain unquantified. This is capability evidence, not income.

Native final-player checks observed both videos playing at 1080 × 1920 with 6-second duration, readyState 4, no media errors and completed loops (4 and 3 at the recorded observation). Ten decoded key frames were visually inspected. Audio encoding and clipping were measured; independent perceptual listening and client style acceptance remain unverified.
